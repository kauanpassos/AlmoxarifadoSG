# Política de Segurança

## Versões Suportadas

Corrigimos ativamente vulnerabilidades de segurança apenas na versão estável mais recente. Por favor, atualize para a versão mais recente para garantir que você tenha todas as correções de segurança.

| Versão | Suportada          | Notas |
| ------ | ------------------ | ----- |
| 1.x.x  | :white_check_mark: | Versão estável atual. |
| 0.y.x  | :x:                | Versões Beta/Desenvolvimento. Atualize para a 1.x.x. |

## Reportando uma Vulnerabilidade

**Por favor, não abra uma Issue pública para relatar vulnerabilidades de segurança.**

Se você descobrir uma falha de segurança neste projeto, reporte-a de forma privada através do próprio GitHub:

1. No GitHub.com, navegue até a página principal do repositório.
2. Abaixo do nome do repositório, clique em **Security** (Segurança).
3. Na barra lateral esquerda, na seção "Reporting", clique em **Advisories** (Avisos).
4. Clique em **Report a vulnerability** (Reportar uma vulnerabilidade) para abrir o formulário confidencial.

### O que Esperar

* **Confirmação:** Você receberá uma resposta inicial em até **48 horas** confirmando o recebimento do relatório.
* **Atualizações:** Enviaremos atualizações de status pelo menos uma vez a cada **7 dias** enquanto analisamos e corrigimos o problema.
* **Resolução:** Se a vulnerabilidade for aceita, uma correção será desenvolvida em uma branch de segurança privada e coordenada com você antes do lançamento público e da atribuição do CVE.
